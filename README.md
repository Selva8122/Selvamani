# Selvamani Portfolio

This repository contains a Docusaurus-based documentation portfolio for showcasing technical writing, doc-as-code workflows, and CI/CD automation.

## Local development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

## Deployment

The repository includes a GitHub Actions workflow for automatic deployment to GitHub Pages.

## Included in the portfolio

- Technical writing samples
- Process and documentation workflow overview
- Project highlights and case studies
- CI/CD and doc-as-code examples

---

Built with Docusaurus and designed as a doc-as-code portfolio site.
