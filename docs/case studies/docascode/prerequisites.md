# Tools and Prerequisites

| Tool | Purpose | Download |
| --- | --- | --- |
| Node.js (LTS) | Runtime that runs Docusaurus. Installs npm the package manager. | https://nodejs.org |
| Git | Version control for the source files. | https://gitscm.com/downloads |
| Visual Studio Code | Editor for Markdown and configuration files. | https://code.visualstudio.com |
| GitHub Desktop | Graphical Git client for committing and pushing | https://desktop.github.com |
| GitHub | account Hosts the repository, runs Actions and serves Pages. | https://github.com |

After installing Node.js, open a new terminal and confirm both commands return a version number: <br></br>

```node -version```<br></br>
```npm --version```<br></br>

You do not need to write JavaScript to author content. You only edit it when you change site settings.
