# Technical writing portfolio

I help product teams document what matters most: product value, user workflows, release changes, and operational clarity. My work sits at the intersection of user empathy, developer enablement, and well-structured documentation systems.

## What I do

- Write clear user-facing product documentation and onboarding content.
- Build internal docs for engineering, support, and product operations.
- Design doc-as-code workflows that scale with the product and team.
- Create publishable docs experiences with Docusaurus, Markdown, and CI/CD automation.

## Why this portfolio matters

This site demonstrates how I approach writing as a product function: easy to maintain, easy to search, and easy to improve over time.

The portfolio is built using:

- Docusaurus for documentation site generation
- Doc-as-code workflows with Markdown and Git versioning
- CI/CD automation for linting, build validation, and deployment
- A structure designed to showcase writing samples, process, and system setup
