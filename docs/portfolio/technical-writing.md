# Technical writing samples

## Writing approach

I write documentation that helps users understand the product quickly and helps teams maintain consistency over time. My focus is on clarity, task orientation, and maintainability.

### Typical deliverables

- Product feature guides and onboarding flows
- Developer API documentation and reference material
- Release notes and operational updates
- Troubleshooting and admin guides
- Internal enablement content for support and customer success teams

## Example of effective documentation

A strong documentation set includes:

1. Clear problem framing
2. Step-by-step task guidance
3. Scannable sections and headings
4. Example usage when needed
5. Controlled language and consistent terminology

## Documentation value

Good documentation reduces support load, shortens onboarding time, and improves confidence in product adoption. I prioritize the user journey and make sure the docs reflect the actual experience of using the product.
